# `src/` — the game

Empty by design. The three layers that live here — `sim/`, `state/` and
`render/` (see [ADR-0006](../docs/adr/0006-three-layers-sim-presentation-renderer.md))
— are created in [M0.3](../docs/plan/m0-foundations.md#m03--the-three-layer-skeleton-and-the-boundary-that-enforces-it),
together with the portability checker that keeps the boundary between them
honest. M0.2 is the scaffold only.
