# Specs

Empty until [M0.1](../plan/m0-foundations.md) writes it.

Per [ADR-0002](../adr/0002-specs-are-canonical-for-behaviour.md), these files are canonical
for **behaviour and numbers**; the design boards in `../design/` stay canonical for
**appearance**. Every spec cites its board, or states that it has none.

Specs `00`–`12` are transcribed from the twelve design directions. Specs `01` and `13`–`17`
have no board and are authored: the swing's characteristics, fuel, the retro grade, audio,
powerups, and the daily field's difficulty curve.

M0.1 lists the rulings that resolve the contradictions between boards. Apply them; they were
decided deliberately and are not open.
